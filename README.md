# Adhi Narayanan P — Portfolio

Next.js 14 (App Router) + TypeScript + Tailwind CSS + Framer Motion + Lucide React.

```bash
npm install
npm run dev     # http://localhost:3000
```

- **Images:** portrait, marquee GIFs and project pictures are the template images, listed in `lib/images.ts`.
  Replace the URLs there (or use files from `public/`) with your own photo and screenshots.
- **Content:** `lib/data.ts` holds services, projects and contact details.
- **Resume:** replace `public/Adhi_Narayanan_P_Resume.pdf`.
